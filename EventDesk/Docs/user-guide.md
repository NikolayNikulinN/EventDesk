# EventDesk — руководство пользователя

## Установка

1. Запустите `EventDesk.Installer.exe` на 64-разрядной Windows с правами администратора и нажмите **Install**.
2. Установщик разместит программу в `C:\Program Files\EventDesk`, создаст ярлыки в меню «Пуск» и на рабочем столе и запустит службу **EventDesk Service**.
3. Откройте **EventDesk** через ярлык. Для работы календаря и напоминаний служба должна быть запущена. При следующих входах в Windows приложение запускается в трее; обычный ярлык открывает его окно.

Пакет содержит .NET 9 вместе с приложением и службой: отдельная установка .NET Runtime не нужна. При первом запуске служба создаёт базу в `%ProgramData%\EventDesk\Data\EventDesk.db`.

## Календарь и события

- На странице **Calendar** выберите день в мини-календаре, затем создайте событие в недельном календаре.
- Нажмите на событие, чтобы изменить, отключить или удалить его.
- Для напоминания выберите уведомление Windows, электронную почту или оба канала. Можно настроить время напоминания до начала события и повторную доставку.
- В **History** показаны канал, статус доставки, число попыток и последняя ошибка.

## Уведомления Windows

Оставьте EventDesk запущенным в области уведомлений (трее). Закрытие окна скрывает его, а приложение продолжает получать напоминания. Нажмите значок трея или команду **Open**, чтобы открыть окно. Команда **Exit** завершает приложение. Если EventDesk не запущен, служба повторит попытку доставки позже; для показа уведомления приложение нужно снова открыть.

## Электронная почта

На странице **Settings** включите **Enable email delivery**, заполните SMTP host, port, user name, password и From address, добавьте адреса получателей, затем нажмите **Save email settings**. Для STARTTLS обычно используется порт 587, для TLS — 465; уточните параметры у почтового провайдера. Получатели сохраняются вместе с почтовыми настройками.

Служба хранит настройки почты в `%ProgramData%\EventDesk\Data\MailSettings.dat`, защищённые Windows DPAPI под учётной записью службы. После установки служба работает под LocalSystem; при смене её учётной записи потребуется ввести пароль заново. Статус **Delivered** означает, что SMTP-сервер принял письмо, а не гарантирует его появление в папке «Входящие».

## Обновление и удаление

Чтобы обновить EventDesk, закройте приложение через **Exit** в трее и запустите установщик более новой версии. Установщик остановит службу, заменит файлы и снова запустит её. События, история и почтовые настройки останутся в ProgramData.

Удалите программу через **Установленные приложения** Windows или установщик. Служба и ярлыки будут удалены. Каталог `%ProgramData%\EventDesk\Data` намеренно остаётся, чтобы события и настройки можно было восстановить после повторной установки. Для полного удаления данных после деинсталляции удалите этот каталог вручную с правами администратора.

Если календарь сообщает, что служба недоступна, проверьте состояние **EventDesk Service** в `services.msc`. При проблемах с установкой откройте журнал из окна установщика. Приложение и служба также ведут журналы в своих каталогах логирования.
